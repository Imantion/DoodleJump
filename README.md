# Doodle Jump Project (Pure C++ with Custom Sprite Renderer Framework)



This is a simple implementation of the classic *Doodle Jump* game, developed entirely in pure C++ using a custom sprite rendering framework. All the game logic, physics, and rendering systems were built from scratch.

---

## Features

- **Custom Sprite Renderer Framework**: Developed to handle sprite rendering efficiently in pure C++.
- **Physics and Game Logic**: Includes platform generation, gravity simulation, and collision detection, all implemented manually.
- **Classic Gameplay Mechanics**: Replicates the core mechanics of *Doodle Jump*, ensuring smooth and responsive gameplay.

## Getting Started

### Prerequisites

- **Visual Studio 2022**: Required for compiling and running the project.

### Installation

1. Clone the repository to your local machine.
   ```bash
   git clone https://github.com/Imantion/DoodleJump.git
   ```
2. Open the project in Visual Studio 2022.

### Running the Project

- Build and run the project from Visual Studio.
- If you encounter any DLL-related errors:
  1. Locate the missing DLL files.
  2. Copy them to the `.exe` directory folder within the build output path.
